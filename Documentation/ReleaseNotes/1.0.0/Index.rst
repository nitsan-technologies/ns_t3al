======================
1.0.0  19 October 2026
======================

Here is the list of features and updates introduced in this release:

.. code-block:: none

   19-10-2026 [FEATURE] XLF file translation with AI: translate .xlf language files using AI, filling only empty labels
   19-10-2026 [FEATURE] Multi-provider translation support: OpenAI, DeepL, Google Translate and Google Gemini
   19-10-2026 [FEATURE] Crowdin integration: upload translations of TYPO3 system extensions directly to Crowdin
   19-10-2026 [FEATURE] Backend translation editor: edit, search, import and export XLF translations in the TYPO3 backend
   19-10-2026 [FEATURE] Translation logs with per-label diff, and per-extension access rights for editors
   19-10-2026 [TASK] TYPO3 v12/v13/v14 compatibility with PHP 8.2 to 8.5
   19-10-2026 [TASK] Composer and TER installation support
   19-10-2026 [TASK] Follows the official TYPO3 extension development checklist
   19-10-2026 [TASK] Automatic code review and tests with GitHub Actions
   19-10-2026 [BUGFIX] Functional testing, UI/UX improvements and final bug fixes
   19-10-2026 [RELEASE] Initial stable release v1.0.0
