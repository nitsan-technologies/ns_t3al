ChangeLog
=========

Version 1.0.0
=============

Initial release.

*  Free, no license key or license activation needed.
*  **AI-Powered XLIFF Translation** with the backend module
   :guilabel:`AI Localization` and its own extension and module icons. On
   TYPO3 v14 the module icon follows the backend theme.
*  Support for TYPO3 12.4 LTS, 13.4 LTS and 14.3 LTS.
*  Translation providers DeepL, OpenAI, Google Gemini and Google Translate
   with structured, count-checked requests; only empty translations are
   filled.
*  Redesigned module with :guilabel:`Translate`, :guilabel:`Search` and
   :guilabel:`Logs` tabs and an interactive guide.
*  Saving keeps the XLIFF formatting and only writes changed files.
*  Crowdin upload for TYPO3 system extensions.
*  CSV import (merge) and export, ZIP export, label search.
*  Access rights per extension for non-admin backend users.
*  Translation logs with diff, pagination and retention period.
